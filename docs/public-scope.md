# 公开范围、隐私与版权边界

## 为什么不是把原始目录原样上传

原始资料合集约 5.9 万个文件、约 11 GB，包含视频、安装包、编译输出、重复备份、离线知识库数据库和官方/第三方资料。GitHub 普通仓库单文件上限为 100 MB，且公开发布这些内容还会带来版权、隐私和供应链风险。因此本仓库只发布可读、可复现、适合求职展示的源码和说明。

## 纳入公开版的内容

- 国赛工程模板的 APP、Bootloader、上位机源码、构建脚本和 Markdown 文档。
- 初赛 GD32F470 APP/OTA 工程的核心源码、Keil 工程和工程说明。
- 采样、Modbus RTU、TF/FatFs、Flash 分区、标定、故障排查和验收资料。
- 经过整理的架构说明、资料索引和工程边界说明。

## 明确排除的内容

- `.mp4` 视频、演示录像和大于 100 MB 的 PDF。
- Keil、STM32CubeMX、驱动包等安装器和第三方软件分发包。
- `.o`、`.axf`、`.map`、`.crf`、`.d`、`.dep` 等编译生成物。
- `knowledge.db` 等离线知识库数据库、缓存和索引。
- 含有重复工程、自动生成缓存或无法确认再分发许可的压缩包。
- 队伍编号、学校/成员/指导教师等身份信息（公开前需再次人工检查）。

## 使用提醒

1. 正式比赛题目、裁判说明和硬件手册优先级高于本仓库。
2. 默认增益、阈值和分区只代表当前模板，不应直接用于生产或正式比赛承诺。
3. 复制、修改或再分发第三方库时，请遵循其随附许可证和版权声明。
4. 提交导师或面试材料前，建议再次扫描 Windows 用户名、绝对路径、图片 EXIF、Office 作者属性和串口日志。
