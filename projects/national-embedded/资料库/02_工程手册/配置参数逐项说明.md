# 配置参数逐项说明

文件：`APP/HeaderFiles/contest_config.h`。

| 宏 | 默认值 | 作用 | 改后是否立即闭环 |
|---|---:|---|---|
| `CONTEST_PROTOCOL_MODE` | Modbus RTU | 选择比赛协议 | 当前仅 Modbus 路径完整接入 |
| `CONTEST_MODBUS_SLAVE_ADDRESS` | 1 | 从站地址 | 重新编译后生效 |
| `CONTEST_MODBUS_BAUDRATE` | 19200 | RTU 波特率 | 重新编译后生效 |
| `CONTEST_SAMPLE_PERIOD_MS` | 100 | 采样任务周期 | 重新编译后生效 |
| `CONTEST_LOG_PERIOD_MS` | 1000 | TF 日志周期 | 重新编译后生效 |
| `CONTEST_TF_LOG_ENABLE` | 1 | 是否初始化和写 TF | 重新编译后生效 |
| `CONTEST_TF_LOG_PATH` | `0:/CIMC_DATA.CSV` | 日志路径 | 文件名应使用 FatFs 支持格式 |
| `CONTEST_ADC_CH_*` | 0/1/2 | 三种工程量的逻辑通道 | 重新编译后生效 |
| `CURRENT_GAIN/OFFSET` | 10/0 | 电流线性换算 | 必须实板标定 |
| `VOLTAGE1_GAIN/OFFSET` | 5/0 | 电压 1 换算 | 必须单独标定 |
| `VOLTAGE2_GAIN/OFFSET` | 5/0 | 电压 2 换算 | 必须单独标定 |
| `CONTEST_WIRE_BREAK_MA` | 3.5 | 断线判定阈值 | 无迟滞、无去抖 |

## 容易误解的地方

保持寄存器 40001~40003 初始化时复制了采样周期、日志周期和使能值，但调度器仍使用编译期宏。因此通过 Modbus 写 40001 不会改变采样周期。需要动态生效时：

1. 建立运行时配置结构体。
2. 写保持寄存器时检查上下限。
3. 调度器读取运行时周期，而不是固定数组初值。
4. 根据正式题决定是否保存到参数区。
5. 上电加载后再次做范围检查，损坏时恢复默认值。

## 建议范围

这些是工程建议，不是样题强制值：采样周期不宜小于一次三通道转换所需总时间；日志周期不宜短到让 `f_sync` 长时间占用主循环；Modbus 地址限定 1~247；波特率必须与端口定时计算和现场上位机一致。
