# 代码修改地图

| 现场要求变化 | 首选修改点 | 同时检查 |
|---|---|---|
| 从站地址/波特率 | `contest_config.h` | RS485 port 定时器、上位机配置 |
| 采样周期/日志周期 | `contest_config.h` | 若需运行时可写，改 `contest_main.c` 调度结构 |
| 通道接线变化 | `contest_config.h`、`contest_adc.c` | PCB 原理图、三路实测对应关系 |
| 比例/零偏 | `contest_config.h` | 标定记录、误差计算 |
| 断线逻辑 | `contest_app.c` | 状态位、UI、CSV、迟滞/去抖 |
| 输入寄存器 | `contest_modbus.h/.c` | 地址从 0/1 的约定、倍率、字节序 |
| 保持寄存器 | `contest_modbus.c` | 权限、范围、动态生效、掉电保存 |
| 线圈/离散量 | 四个 FreeModbus 回调 | 位打包顺序和功能码 |
| CSV 文件名/列 | `contest_storage_final.c` | 表头、格式、缓存长度、卡容量 |
| TF 热插拔 | 新增存储状态机 | 卡检测 GPIO、卸载/重挂载、错误位 |
| 中断冲突 | `contest_irq_all.c` | 原 `gd32f4xx_it.c` 是否仍参与编译 |
| FreeModbus 端口 | `contest_port_clocked.c` | USART1、DE/RE、T3.5 定时器 |
| APP 起始地址 | `.uvprojx`/scatter/`ota_def.h` | Bootloader 跳转、VTOR、烧录地址 |
| 固件大小上升 | `FW_BUF_MAX` 或升级架构 | RAM、APP 分区、接收超时、CRC |

原则：每项需求只指定一个“唯一配置源”。同一个地址若散落在多个头文件里，先统一再继续开发。
