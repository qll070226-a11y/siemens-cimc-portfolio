# 离线工具使用说明

## 搜索文字

在资料库目录打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\06_离线工具\搜索资料库.ps1 Modbus
```

脚本搜索 Markdown、CSV、日志、文本和 HTML。PDF 内容请从首页直接打开，或按页码索引定位。

## 检查资料完整性

```powershell
powershell -ExecutionPolicy Bypass -File .\06_离线工具\检查资料库.ps1
```

它检查核心文档、权威原文、FreeModbus 原包以及两份构建日志是否齐全，并确认日志为 0 error、0 warning。

## 打开首页

双击工程根目录 `打开资料库.bat`，或直接双击 `资料库/index.html`。页面只使用本地文件，不需要网络和服务端。
