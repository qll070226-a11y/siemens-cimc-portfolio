# CIMC 2026 工业嵌入式系统开发国赛离线资料库

这是与 `CIMC_2026_国赛工程模板` 配套的离线资料库。比赛现场建议先双击根目录的 `打开资料库.bat`，或直接打开 `index.html`。

## 使用原则

1. 现场正式赛题、裁判说明高于本资料库和样题。
2. 标为“已实现”的能力，表示源码和 Keil 构建已核对；仍需在实际控制板、采样板和信号源上联调。
3. 标为“预留”的能力，只表示寄存器或接口已经留出，不可当作已完成。
4. 标为“必须标定”的参数不可直接使用模板默认值提交。
5. 修改前复制整个工程形成时间戳备份，始终保留一个可编译基线。

## 目录含义

| 目录 | 用途 |
|---|---|
| `00_导航` | 快速入口、来源页码、需求追踪和现场顺序 |
| `01_权威原文` | 样题、初赛题、参赛指南、Modbus 文档和原始库 |
| `02_工程手册` | 工程结构、编译、烧录、配置、分区和限制 |
| `03_专题速查` | 采样、标定、Modbus、TF、RS485、PCB、排障 |
| `04_现场表单` | 可打印或直接填写的记录表和检查表 |
| `05_构建基线` | 已通过的构建结果、文件哈希和复核说明 |
| `06_离线工具` | 资料库搜索、完整性检查和现场辅助脚本 |

## 版本说明

本资料库根据全国总决赛样题、初赛赛题及当前模板源码整理。真正国赛题目可能增加或改变寄存器、采样周期、文件格式和交互协议。收到现场题后，先做差异表，再改代码。
