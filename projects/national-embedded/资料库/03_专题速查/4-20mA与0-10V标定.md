# 4~20mA 与 0~10V 标定

## 目标

样题要求一路 4~20mA 和两路 0~10V 误差不大于 ±1%。建议以满量程百分比计算并同时记录绝对误差；最终按现场题给出的误差定义。

## 准备

- 校准过的电流/电压源或可追溯信号发生器。
- 万用表复核实际输入。
- 能观察 ADC 端电压或原始码的调试方式。
- `04_现场表单/标定记录表.csv`。

## 两点求系数

对每个通道分别取两个相距较远的点。`X` 为 ADC 端电压，`Y` 为输入工程量：

```text
gain   = (Y2 - Y1) / (X2 - X1)
offset = Y1 - gain × X1
```

电流建议以 4mA、20mA 求初值；电压以 0V 附近和 10V 求初值。0V 点如受单电源偏置影响，应使用实际可稳定测到的低点。

## 多点验证

电流：4、8、12、16、20mA。电压每路：0、2、4、6、8、10V。每点：

1. 信号稳定后等待至少 3 个采样周期。
2. 取 10~100 次平均。
3. 记录真值、显示值、绝对误差。
4. 按现场定义计算百分比误差。
5. 找最大误差点，不只看端点。

常用满量程误差：

```text
电流误差%FS = |测量值 - 真值| / 16mA × 100%
电压误差%FS = |测量值 - 真值| / 10V × 100%
```

若正式题采用相对读数误差，0V 附近不可直接除以真值，应严格采用题目定义。

## 精度不达标的判断

- 所有点接近同一固定偏差：调 offset。
- 偏差随输入线性增大：调 gain。
- 中间点弯曲：硬件非线性、饱和、参考或滤波问题，线性两参数无法修复。
- 抖动大但均值准确：增加合理平均/滤波，检查电源、地、屏蔽和 SPI。
- 两电压通道误差不同：分别标定，不能共用系数。

## 断线阈值

正常下限为 4mA，模板阈值 3.5mA。实测开路、短路、3.4/3.5/3.6/4.0mA，确认不会把正常 4mA 误报。若噪声造成跳变，使用迟滞和连续样本计数。
