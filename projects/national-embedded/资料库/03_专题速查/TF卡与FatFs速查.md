# TF 卡与 FatFs 速查

## 当前流程

```text
disk_initialize(0)
  -> f_mount
  -> f_open(OPEN_ALWAYS|WRITE)
  -> 空文件写表头
每秒：open -> seek end -> write -> sync -> close
```

## 错误返回定位

初始化：`-1` 磁盘初始化失败，`-2` 挂载失败，`-3` 打开失败，`-4` 表头写失败，`-5` 关闭失败。

追加：`-1` 未挂载，`-2` 行格式/缓冲错误，`-3` 打开失败，`-4` seek/write/sync/close 失败。

当前上层只把错误折叠为 `tf_error=1`。调试时可临时打印具体返回值，但提交前避免大量串口打印阻塞 Modbus。

## 测试矩阵

| 场景 | 期望 |
|---|---|
| 空白可识别卡 | 建文件并写一次表头 |
| 已有日志 | 追加，不重复表头 |
| 未插卡启动 | 主程序仍运行，状态 bit2 提示错误 |
| 运行中拔卡 | 写失败，不应死机；当前不会自动恢复 |
| 再插卡 | 当前需复位才能重新初始化 |
| 写入时 Modbus 轮询 | 响应仍在允许超时内 |
| 突然断电 | 重新插电脑检查文件系统和末行 |

## 现场优化方向

- 要热插拔：增加存储状态机和重试间隔，不能在 1ms 循环反复 mount。
- 要真实时间：用 RTC 生成日期时间列，并定义时区/格式。
- 要高频日志：批量缓存多行后写入，但要权衡断电丢失。
- 要防止文件无限增长：按大小/日期轮转，并处理磁盘满。
