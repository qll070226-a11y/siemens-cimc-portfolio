# 故障排查手册

## 程序不运行

1. 读 `0x08011000` 前两个字，栈应在 `0x200xxxxx`，复位向量应在 `0x080xxxxx`。
2. 确认 Bootloader 从 `FLASH_APP_ADDR` 跳转，APP map 也是同一地址。
3. 调试器直接从 APP 入口运行，区分 Bootloader 与 APP 初始化问题。
4. 检查 VTOR、MSP、中断清理和看门狗。

## Modbus 无响应

1. 19200 8N1、地址 1。
2. A/B 交换测试，检查 DE/RE。
3. 看请求是否到 MCU RX。
4. 给 RX ISR、T3.5、寄存器回调加计数器。
5. 暂停 TF 和大量日志，排除主循环阻塞。
6. 查端口文件是否只有一个版本参与编译。

## 数值不对

1. 绕开 gain/offset 观察 ADC 端电压。
2. 检查通道 0/1/2 对应 Channel 4/5/6。
3. 用万用表测前端输出，确认没有饱和。
4. 分别求三路系数，不复制电压 1 到电压 2。
5. 检查寄存器倍率：电流 mA×1000，电压为 mV。

## TF 不写

1. 看状态 bit1/bit2。
2. 输出 `contest_storage_init` 具体错误码。
3. 在电脑备份后重新格式化兼容文件系统，换一张已验证卡。
4. 查卡座、SPI/SDIO 接线和供电。
5. 确认日志路径和 FatFs 长文件名配置。

## 写一会儿后卡死

1. 检查 `f_sync` 延迟、卡质量和供电跌落。
2. 检查任务中无限等待外设标志。
3. 减少串口打印。
4. 看栈、格式化缓冲和数组越界。
5. 同时记录系统毫秒和各任务心跳，定位停在哪个任务。

## Bootloader 升级失败

1. 固件是否带 4 字节魔术字。
2. bin 是否超过 48KB 当前 RAM 缓冲。
3. 256B 切片、片间时序、结束空闲时间是否匹配。
4. 擦写地址是否 `0x08011000`，是否误用了遗留 `0x0800D000` 分区。
5. 复位后向量是否合法，APP 是否按正确地址链接。
