# PCB 设计与验收检查

## 样题硬要求

- 同一采样板实现一路 4~20mA、两路 0~10V。
- 三路相互隔离。
- ADC 与主控采用 SPI。
- 覆铜层写明队伍编号；未按要求采样部分扣 20 分。
- 现场端子为 `WJ15EDGK-3.81-02P-14-00A`，不匹配无法测评。
- 样题要求使用嘉立创 EDA 完成 PCB 开发。

## 原理图检查

- 每路输入保护、限流、滤波、量程和极性清楚。
- 4~20mA 采样电阻精度、温漂和功率满足误差预算。
- 0~10V 分压电阻精度、阻抗和 ADC 输入驱动满足要求。
- 隔离器件的耐压、带宽、供电和地划分明确。
- ADC 参考去耦、模拟/数字电源去耦靠近引脚。
- SPI 隔离方向和 CS 默认状态正确。
- 测试点覆盖三路输入、ADC 侧信号、电源、地、SPI。

## PCB 检查

- 隔离间距和禁布区没有被覆铜、过孔、丝印跨越。
- 模拟回流路径短，开关电源和高速数字线远离敏感输入。
- 端子间距、方向、插拔空间与实物完全一致。
- 队伍编号放在要求的铜层，不只是丝印；Gerber 预览可见且方向正确。
- 板边、安装孔、排针和外壳无机械干涉。
- 提交前跑 DRC，导出 Gerber 后再次预览，而不是只看 PCB 编辑器。

## 到板验收

1. 不上芯片先查电源对地短路。
2. 限流供电，逐个电源域测电压和电流。
3. 查隔离两侧地电阻，不应被焊锡/铜皮短接。
4. 用已知输入测前端输出，再连接 ADC。
5. 做五/六点标定、串扰、断线和长时间温漂测试。
