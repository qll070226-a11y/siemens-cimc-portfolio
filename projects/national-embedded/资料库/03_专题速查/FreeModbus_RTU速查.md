# FreeModbus RTU 速查

## 当前默认值

```text
模式    RTU
地址    1
串口    USART1 / RS485
波特率  19200
格式    8N1
轮询    eMBPoll() 每 1ms 调用机会
```

## 当前寄存器

| 类型 | 人类编号 | PDU 起始地址 | 内容 |
|---|---:|---:|---|
| Input | 30001 | 0 | 电流 mA×1000 |
| Input | 30002 | 1 | 电压1 mV |
| Input | 30003 | 2 | 电压2 mV |
| Input | 30004 | 3 | 状态位 |
| Input | 30005 | 4 | sample_count 高字 |
| Input | 30006 | 5 | sample_count 低字 |
| Holding | 40001 | 0 | 采样周期预留 |
| Holding | 40002 | 1 | 日志周期预留 |
| Holding | 40003 | 2 | 日志使能预留 |

FreeModbus 回调接收的地址可能已按库内部规则加 1；当前实现用 `address - 1`。现场抓实际请求和回调，遇到偏一问题不要同时改上位机与下位机。

## 功能码

- `0x04` 读输入寄存器。
- `0x03` 读保持寄存器。
- `0x06` 写单个保持寄存器。
- `0x10` 写多个保持寄存器。
- 线圈和离散输入回调当前返回 `MB_ENOREG`。

## RTU 时序

帧边界依赖至少 3.5 个字符时间的总线静默。19200、8N1 一个字符约 0.521ms，3.5 字符约 1.82ms。端口定时器必须和实际波特率一致。

## 测试报文思路

读从站 1 的 6 个输入寄存器：地址 `0000`、数量 `0006`，CRC 低字节先发。推荐使用离线上位机自动生成 CRC，手工报文只用于抓包核对。

## 写参数时必须补的保护

1. 地址合法。
2. 数值范围合法。
3. 写入为原子更新，非法值不改变旧配置。
4. 需要持久化时采用带版本、魔术字和 CRC 的结构。
5. 回复成功前后何时生效必须符合正式题。

## 无响应优先检查

串口参数 → 从站地址 → A/B 极性 → 共地/隔离参考 → DE/RE 方向 → USART RX 中断 → RTU 定时器 → `eMBPoll` 是否被阻塞。
