# 采样标定与验收

## 上电前检查

1. 确认 24 V、模拟地、数字地、隔离电源方向和端子极性。
2. 限流上电，先检查各电源轨，再连接信号源和主控。
3. 示波器确认 AD3344 的 CS、SCLK、MOSI、MISO 有效且幅值正确。
4. 每次只接一路信号验证，最后三路同时接入检查串扰。

## 修复后逐通道软件验收

先刷入 APP\MDK\output\App.bin，再通过 上位机\run.bat 启动修复版上位机。串口使用 19200、8N1、从站地址 1，实时监控会一次读取 30001~30009。

1. 将未测试的两路电压输入明确接 0 V，不要悬空。
2. 电流通道输入 10.000 mA：AIN1 应约为 +906 mV，AIN0/AIN2 应接近 0 mV，工程量约为 10.000 mA。
3. 电压通道 1 输入 5.000 V：AIN0 应约为 +909 mV，AIN1/AIN2 不应跟随，工程量约为 5.000 V。
4. 电压通道 2 输入 5.000 V：AIN2 应约为 +909 mV，AIN0/AIN1 不应跟随，工程量约为 5.000 V。
5. 再检查满量程：20 mA 对应 AIN1 约 1812 mV；10 V 对应相应 AIN 约 1818 mV。
6. 每次换挡后等待至少 2 秒，记录“ADC原始”一栏、工程量和通信日志。

第一轮只判断通道是否独立、数值数量级是否正确，建议允许理论值 ±10%。三路映射正确后再做两点标定，不要用串道状态下的显示值反推增益和零点。

如果刷入新固件后仍出现 AIN1 跟随 AIN0 或 AIN2 恒为 0，先确认打开的是 CIMC_DebugTool_ADC修复版.exe，再检查 OUTA/AIN0、OUTB/AIN1、OUTC/AIN2 的连续性和实际焊接器件型号。

## 推荐标定点

- 电流：4、8、12、16、20 mA，另测 0 mA 验证断线。
- 电压：0、2.5、5、7.5、10 V，每一路独立标定。
- 每点稳定后采集不少于 20 次，记录平均值、最大值和最小值。

线性换算为 `工程量 = ADC端电压 * gain + offset`。将计算结果写入
`APP\HeaderFiles\contest_config.h`。全量程每个点误差应小于 1%，建议目标控制在 0.5% 内留裕量。

## TF 卡验收

1. 使用 FAT32 格式的已知良好 TF 卡。
2. 上电后读取状态寄存器，bit1 应为 1，bit2 应为 0。
3. 等待至少 5 秒，断电前停止测试或正常复位。
4. 检查 `CIMC_DATA.CSV` 有表头、时间递增、三通道数据和断线状态。
5. 连续运行 30 分钟，确认文件持续追加且 Modbus 无超时。

## 可靠性测试

- 三路满量程同时输入，检查误差和串扰。
- RS485 连续轮询同时写 TF 卡，检查丢帧率。
- TF 卡缺失、写保护或损坏时，系统仍应采样和响应 Modbus。
- 电流回路断开/恢复，状态应可靠翻转且无频繁抖动；必要时增加迟滞和连续计数判定。
- 反复断电上电，确认参数、Bootloader 和 APP 均可正常启动。
