# CIMC 2026 比赛调试上位机

双击 `CIMC_DebugTool_ADC修复版.exe` 或 `run.bat` 运行。程序基于 Windows 自带的 .NET Framework 4.x，不需要联网、Python、Node 或额外串口库。

## 快速连接

1. 插入 USB-RS485，点击“刷新”。
2. 选择 COM 口，默认 `19200 / None / 8 / 1`，从站地址 `1`。
3. 点击“打开串口”。
4. 在“实时监控”页点击“开始轮询”。
5. 正常时应每 500ms 更新电流、电压、TF 状态和采样计数。

没有硬件时点击“离线模拟”，可演练监控、CSV 和通用寄存器读写。

## 实时监控

固定读取输入寄存器 PDU 地址 0~8（人类编号 30001~30009）：

| 地址 | 内容 | 换算 |
|---:|---|---|
| 30001 | 电流 | 原值 / 1000 = mA |
| 30002 | 电压 1 | 原值 / 1000 = V |
| 30003 | 电压 2 | 原值 / 1000 = V |
| 30004 | 状态 | bit0 断线，bit1 TF 就绪，bit2 TF 错误 |
| 30005/30006 | 采样计数 | 高 16 位、低 16 位 |
| 30007 | GD30AD3344 AIN0 原始电压 | 有符号 16 位，单位 mV |
| 30008 | GD30AD3344 AIN1 原始电压 | 有符号 16 位，单位 mV |
| 30009 | GD30AD3344 AIN2 原始电压 | 有符号 16 位，单位 mV |

30007~30009 是故障诊断值，不经过标定系数。只接一路信号时，应只有对应 AIN 明显变化；通用寄存器页选择“有符号”也可单独读取核对。

勾选“同时保存 CSV”可记录 PC 时间和测量值。默认保存到上位机 `logs` 目录。

### 趋势曲线与离线回放

“实时监控”页默认显示三通道趋势曲线：

- 电流使用左侧 Y 轴（mA），电压 1/2 使用右侧 Y 轴（V），避免不同量纲互相压缩。
- “显示点数”可选 60、120、300、1000；内存最多保留最近 5000 条，长期数据请同时保存 CSV。
- 勾选“冻结曲线”只暂停重绘，轮询、数据表和 CSV 仍继续工作；取消勾选后从缓存恢复最新曲线。
- “清空数据”只清空内存曲线和数据表，不停止串口，也不删除已有 CSV。
- “导入 CSV”可离线恢复本工具生成的监控记录；导入前会停止轮询，非法行会跳过并写入日志。
- “导出曲线图”保存当前可见窗口为 PNG，适合报告、答辩和故障对比。

推荐现场流程：先离线模拟确认曲线与 CSV，再接实物；出现瞬态异常时先冻结观察，但保持 CSV 勾选，随后导出 PNG 并保存通信日志。

## 通用寄存器

- 支持功能码 03、04、06、10。
- 地址输入采用 PDU 的 0 基地址。例如 30001/40001 都填地址 `0`。
- 显示无符号、有符号和十六进制，方便现场核对倍率和状态位。
- 扫描地址会遍历 1~247；为控制总时长，每地址超时不超过 120ms。

注意：当前模板固件的 40001~40003 虽可写入 RAM，但不会动态改变采样/日志任务周期，也不掉电保存。

## 原始报文

输入十六进制字节，可自动追加 Modbus CRC。接收采用 30ms 空闲判定。用于正式题临时新增功能码、异常帧和抓包复现。

## 初赛协议与升级

“生成/发送”使用初赛 ASCII-HEX 帧，不是 Modbus。设备 ID 和命令字用十六进制显示。

升级流程：发 `0x0501` 让 APP 进入 Bootloader；等待 1.2 秒后发 `0x0502`；等待 500ms，以 256 字节一片、片间 5ms 发送固件；收到 OK 后发 `0x0503`；设备复位后重新连接验证。

固件必须以 `5A A5 C3 3C` 开头且不超过当前 Bootloader 的 48KB RAM 接收缓存。升级前必须准备调试器直烧恢复方式。正式题改变协议或分区时禁止直接使用该按钮。

## RS485 无响应排查

1. 核对 19200、8N1、地址 1。
2. 检查 USB-RS485 是否被其他软件占用。
3. 交换 A/B 验证命名差异。
4. 只有 TX 没有 RX 时查接线、DE/RE 和下位机。
5. 有 RX 但报 CRC 错时查波特率、干扰、回波和帧边界。
6. 先用输入寄存器地址 0、数量 1 验证最短链路。

## 构建与测试

- `build_final.bat`：UTF-8、警告级别 4、Release 优化构建。
- `test_fixed.bat`：协议向量和 CRC 单元测试。
- `--smoke 截图路径 CSV路径`：自动完成离线模拟、CSV 写入、清空后回放、曲线 PNG 导出和窗口截图，仅用于测试。
